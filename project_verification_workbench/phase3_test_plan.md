## 1. 测试计划概要

### 1.1 测试目标

验证项目在mock环境下的功能完整性、代码质量和安全边界。

### 1.2 测试范围

- **单元测试**：核心模块的功能测试
- **集成测试**：模块间的交互测试
- **安全边界测试**：输入验证、权限控制测试

### 1.3 测试环境

- **Python测试框架**：pytest
- **Mock工具**：unittest.mock
- **测试目录**：tests/

## 2. 测试用例清单

### 2.1 单流程测试（A类）

#### A_001: 查看报告
- **测试目的**：验证报告加载功能
- **测试输入**：有效日期和报告名
- **预期结果**：报告正常加载
- **测试类型**：单元测试

#### A_002: Agent聊天
- **测试目的**：验证Agent聊天功能
- **测试输入**：用户问题
- **预期结果**：返回带引用的回答
- **测试类型**：单元测试

#### A_003: 系统状态
- **测试目的**：验证系统状态查询
- **测试输入**：无
- **预期结果**：返回系统状态
- **测试类型**：单元测试

### 2.2 交汇点测试（B类）

#### B_001: Agent与检索器交互
- **测试目的**：验证Agent与检索器的交互
- **测试输入**：用户问题
- **预期结果**：检索结果正确传递
- **测试类型**：集成测试

#### B_002: 服务器与Agent交互
- **测试目的**：验证服务器与Agent的交互
- **测试输入**：API请求
- **预期结果**：响应正确返回
- **测试类型**：集成测试

### 2.3 安全边界测试（C类）

#### C_001: 输入验证
- **测试目的**：验证输入验证机制
- **测试输入**：空输入、超长输入、特殊字符
- **预期结果**：正确拒绝或处理
- **测试类型**：安全边界测试

#### C_002: API Key认证
- **测试目的**：验证API Key认证机制
- **测试输入**：无效API Key
- **预期结果**：拒绝访问
- **测试类型**：安全边界测试

#### C_003: 速率限制
- **测试目的**：验证速率限制机制
- **测试输入**：超过限制的请求
- **预期结果**：返回429状态码
- **测试类型**：安全边界测试

### 2.4 错误传播测试（D类）

#### D_001: 数据库连接失败
- **测试目的**：验证数据库连接失败的处理
- **测试输入**：数据库不可用
- **预期结果**：返回友好错误信息
- **测试类型**：错误传播测试

#### D_002: LLM API失败
- **测试目的**：验证LLM API失败的处理
- **测试输入**：LLM API不可用
- **预期结果**：返回友好错误信息
- **测试类型**：错误传播测试

### 2.5 状态隔离测试（E类）

#### E_001: 配置隔离
- **测试目的**：验证配置的隔离性
- **测试输入**：不同配置
- **预期结果**：配置互不影响
- **测试类型**：状态隔离测试
