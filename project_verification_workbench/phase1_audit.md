## 5. 架构评估

### 5.1 系统架构

```
用户 → 前端仪表盘 → FastAPI服务器 → Agent → 检索 → 引用 → 响应
                           ↓
                    ChromaDB + Neo4j
                           ↓
                    外部搜索引擎
```

### 5.2 模块依赖

| 模块 | 依赖 | 被依赖 |
|------|------|--------|
| server.py | config, agent, retriever | 无 |
| chat_service.py | agent, retriever, search | server |
| agent/tools.py | retriever, graphrag | agent |
| retriever/hybrid.py | vector_store, neo4j | agent |
| graphrag/driver.py | neo4j | agent |

### 5.3 数据流

1. **用户输入** → API端点
2. **API端点** → 聊天服务
3. **聊天服务** → Agent
4. **Agent** → 检索工具
5. **检索工具** → ChromaDB + Neo4j
6. **检索结果** → 引用生成
7. **引用** → 用户响应
