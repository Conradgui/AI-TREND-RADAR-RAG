## 2. 详细流程分析

### P0_001: 查看报告

**流程步骤**：
1. 用户打开仪表盘
2. 用户选择日期
3. 用户选择报告
4. 系统加载报告
5. 用户阅读报告

**交汇点**：
- **仪表盘**：所有用户操作的入口

**失败模式**：
- 报告文件不存在
- 报告格式错误
- 网络连接失败

**测试类型**：单流程测试

**需要真实API**：否

**Benchmark候选**：否

---

### P0_002: Agent聊天

**流程步骤**：
1. 用户打开Agent
2. 用户输入问题
3. Agent思考
4. Agent检索语料
5. Agent生成回答
6. 系统添加引用

**交汇点**：
- **Agent**：所有聊天请求的处理中心
- **检索器**：向量检索和图谱检索的融合点

**失败模式**：
- 检索无结果
- 生成回答失败
- 引用生成失败

**测试类型**：单流程测试

**需要真实API**：是

**Benchmark候选**：是

## 3. 交汇点分析

### 3.1 仪表盘

**经过的流程**：
- P0_001: 查看报告
- P0_002: Agent聊天
- P0_003: 查看系统状态
- P1_001: 联网搜索
- P1_002: 查看Briefs

**出错影响**：
- 所有用户操作失败

**保存/读取状态**：
- 读取：报告数据、系统状态、Briefs列表
- 保存：无

---

### 3.2 Agent

**经过的流程**：
- P0_002: Agent聊天
- P1_001: 联网搜索

**出错影响**：
- 聊天功能失败

**保存/读取状态**：
- 读取：用户输入、检索结果
- 保存：聊天历史、引用

---

### 3.3 检索器

### 3.4 服务器

## 4. 顺序依赖

### 4.1 必须先完成

1. **数据摄取**：必须先完成数据摄取，才能进行检索
2. **数据库连接**：必须先连接数据库，才能进行查询
3. **配置加载**：必须先加载配置，才能启动服务

### 4.2 可以并行

1. **向量检索**和**图谱检索**：可以并行执行
2. **内部搜索**和**外部搜索**：可以并行执行
3. **多个工具调用**：可以并行执行

## 6. Benchmark候选分析

### 6.1 候选路径

| 路径ID | 路径名称 | 候选原因 | 优势维度 |
|--------|---------|---------|---------|
| P0_002 | Agent聊天 | 核心功能，最能体现RAG价值 | 完整性、可审计性、稳定性 |
| P1_001 | 联网搜索 | 扩展功能，体现外部检索能力 | 完整性、可控性 |

### 6.2 Benchmark设计建议

**任务设计**：
- **BM_001**: 内部语料查询（P0_002）
- **BM_002**: 联网搜索查询（P1_001）
- **BM_003**: 混合查询（P0_002 + P1_001）

**评分维度**：
- **完整性**：任务是否完整完成（0-10）
- **可审计性**：是否有日志/状态记录（0-10）
- **稳定性**：错误是否被正确处理（0-10）
- **可控性**：执行过程是否在预定边界内（0-10）
- **用户体验**：失败时是否给出有帮助的提示（0-10）
