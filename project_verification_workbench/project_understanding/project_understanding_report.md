## 1. 项目概述

### 1.1 项目定位

**AI Trend Radar RAG** 是一个**本地AI研究驾驶舱**，用于：
- 读取最新AI趋势报告
- 基于本地知识库的智能问答（带引用）
- 生成Trend Brief研究制品
- 所有证据可追溯、可验证

### 1.2 目标用户

- AI产品经理
- AI内容运营
- 产品调研人员

### 1.3 核心价值

- **本地优先**：数据存储在本地，无需上传云端
- **证据可追溯**：所有回答都有引用来源
- **智能检索**：结合向量检索和图谱检索
- **一键启动**：双击即可使用

### 2.2 核心模块

| 模块 | 文件 | 职责 |
|------|------|------|
| 服务器 | server.py | API服务、速率限制、认证 |
| 聊天服务 | chat_service.py | Agent编排、引用生成 |
| Agent | agent.py | 工具调用、推理链 |
| 工具 | tools.py | 检索、搜索、抓取 |
| 检索器 | hybrid.py | 向量+图谱混合检索 |
| 图谱驱动 | driver.py | Neo4j查询 |
| 配置 | config.py | 环境变量管理 |
| 指标 | metrics.py | 性能指标收集 |
| 一致性 | consistency.py | 数据一致性校验 |

### 2.3 数据流

```
用户输入
    ↓
API端点 (/chat)
    ↓
聊天服务 (build_chat_response)
    ↓
Agent (create_agent)
    ↓
工具调用 (search_corpus, web_search, etc.)
    ↓
检索器 (HybridRetriever)
    ↓
ChromaDB + Neo4j
    ↓
引用生成 (citations.py)
    ↓
用户响应
```

## 3. 用户流程

### 3.1 P0核心流程

#### P0_001: 查看报告
- **用户操作**：打开仪表盘，选择日期和报告
- **系统响应**：显示报告内容
- **成功标准**：报告正常加载
- **失败恢复**：刷新页面

#### P0_002: Agent聊天
- **用户操作**：输入问题
- **系统响应**：返回带引用的回答
- **成功标准**：回答有引用来源
- **失败恢复**：重新提问

#### P0_003: 查看系统状态
- **用户操作**：点击系统状态按钮
- **系统响应**：显示系统状态信息
- **成功标准**：状态信息完整
- **失败恢复**：刷新页面

### 3.2 P1重要流程

#### P1_001: 联网搜索
- **用户操作**：启用联网搜索，提问
- **系统响应**：搜索外部内容并返回
- **成功标准**：有外部引用
- **失败恢复**：检查网络连接

#### P1_002: 查看Briefs
- **用户操作**：点击Briefs按钮
- **系统响应**：显示Briefs列表
- **成功标准**：Briefs正常加载
- **失败恢复**：刷新页面

### 3.3 P2边缘流程

#### P2_001: 配置管理
- **用户操作**：修改配置
- **系统响应**：保存配置
- **成功标准**：配置生效
- **失败恢复**：恢复默认配置
