# G1 主体关系与受控反哺 Stage Gate

> 日期：2026-08-27 · 阶段：G1 · 决定：通过，进入 G2

## 产品结果

当前链路已形成两级路径：静态注册表中的主体零模型匹配；注册表未覆盖但含明确命名主体的 Query 才允许一次语义回退。回答中出现的关系不会直接变成事实：只有带有效证据标记的关系句才进入候选，第一方来源或同时包含双方实体 ID 的结构化证据才可晋升。已验证关系下一次由本地记忆命中，并在服务启动时与静态关系一起幂等投影到 Neo4j。

```text
Query → 静态/已验证记忆命中 ───────────────→ 本地扩展
        └─ 未识别命名主体 → 一次语义回退 → 检索/回答
                                         ↓
                              带证据关系句 → candidate
                                         ↓ 强证据
                                      verified
                                         ↓
                               下次本地复用 + Neo4j
```

## 实际变更

- 新增 `EntityRelationMemory`：`candidate / verified / rejected / revoked`、稳定关系 ID、原子写入、证据约束和撤销。
- 未知命名主体不再被“任务分类高置信”掩盖；只有这一缺口触发原有语义回退。
- 新增无额外模型调用的 grounded-answer feedback；普通媒体只留候选，第一方/双实体结构化证据才晋升。
- 已验证学习主体进入下一次本地 Query 解析和关系扩展。
- 静态关系与学习关系分 scope 投影到 Neo4j；图推理同时读取两类已验证边。
- 不存思维链，不把整段对话写入知识库，不让未验证候选影响召回。

## Gate 决定

**通过 G1，进入 G2。**

通过理由：已知主体零模型；未知主体仅一次回退；候选不能越权晋升；撤销立即停止扩展；已验证关系可本地复用并投影 Neo4j；真实主路径性能恢复到秒级。

未关闭：学习关系在运行中先进入后端记忆，Neo4j 投影在下一次服务启动时同步；若 G2 关系问题要求同请求后立即做图查询，再评估后台批量投影，不在热路径同步写图。
