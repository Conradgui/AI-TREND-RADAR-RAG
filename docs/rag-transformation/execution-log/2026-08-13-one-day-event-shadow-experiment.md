# 2026-08-13 单日真实语料事件化影子实验

## 目标与边界

以 2026-08-05 的 20 条分层真实记录验证事件准入架构，不修改正式 ChromaDB、Neo4j 或 Web UI。事件字段由 Codex 根据 Conrad 已确认的产品规则提出，尚未经过逐条独立人工复核；本阶段不验证自动抽取质量，也不报告全系统 Recall/F1。

公开测试 seam 为 `EvidenceRetrievalGateway.retrieve()`。

## 实施内容

- 新增六字段影子转换器 `rag/event_shadow.py`，保持原 ATR 编号不变。
- LexicalStore 透传事件字段，但旧文档仍走兼容路径。
- 重要新闻候选先按 `subject_entity_ids` 过滤；仅提及实体的记录进入排除账本。
- 有事件契约时，准入读取 `content_kind/event_type`；没有契约时保留旧关键词路径。
- 新增 V0/V1/V2 消融评估器并冻结输入哈希。

## 不能被高分掩盖的问题

- V2 仍有 3 个同事件重复占位：Apple–OpenAI 争议和就业调查存在多来源版本。
- V2 OpenAI 主榜 7 条中有 4 条时间可信度低；Anthropic 1 条也为低可信。
- 本日没有足够的历史样本，因此没有验证 background 降级。
- 人工标签已参与开发，1.0 是架构诊断结果，不是独立盲测或生产质量证明。
- 六字段不包含影响广度、深度和讨论度，不能单独完成重要性排序。
