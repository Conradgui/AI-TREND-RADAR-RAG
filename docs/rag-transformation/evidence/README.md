# Evidence Folder

This folder stores verification notes for the AI Trend Radar RAG transformation.

Evidence can include:

- command output summaries
- screenshots or screenshot descriptions
- links to external documentation
- local test result summaries
- corpus sync summaries
- evaluation run summaries

Do not store API keys, tokens, private credentials, or raw secret-containing logs.

When an execution step produces evidence, create a dated markdown file with:

- command or action
- expected result
- actual result
- interpretation
- next action if needed
