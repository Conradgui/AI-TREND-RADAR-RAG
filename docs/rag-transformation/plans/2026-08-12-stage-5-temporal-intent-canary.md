# Stage 5 计划：时间意图 Canary

日期：2026-08-12

## 产品问题

“最近发布”“最近更新”“最近收录”不是同一个问题。若查询路由仍只生成统一的 recent filter，Stage 4 的正确时间字段会在检索入口重新混合。

## 最小契约

| 用户表达 | 时间字段 | 缺失时是否降级 |
|---|---|---|
| 最近发布 / 新发布 | `publication_date` | 否；不能用收录日期冒充 |
| 最近更新 / 最近活跃 | `source_updated_at` | 否 |
| 最近收录 / 本周日报 | `report_date` | 不需要 |
| 最近趋势 / 热门动态 | `effective_date` | 是；代表当前可用的新鲜度视图 |

## 小样先行

1. 先为四类表达写查询理解测试。
2. 验证 metadata filter 选择正确字段。
3. 用三条互斥的人工文档验证错误日期角色不能混入结果。
4. 小样通过后才运行真实索引 Canary。

## Stage Gate

- 最近发布不得召回只有更新时间/收录日期的条目；
- 最近更新不得把 RSS 发布日期当更新时间；
- 最近收录按日报日期工作；
- 泛化热门趋势保持原有 effective-date 行为；
- 独立监管同时检查用户语言与代码过滤字段。
