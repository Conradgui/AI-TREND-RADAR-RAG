# Route Contract v2 人工标注与封存盲测口径

- 版本：`atr.route.annotation/2.0`
- 日期：2026-08-13
- 适用范围：影子 Query Understanding；不代表正式 RAG 回答质量

## 标注顺序

1. 原样保留 Query 与公开的 `conversation_context`；不得根据当前实现输出反推标签。
2. 先按用户的成功标准选择一个主路线：A 单条定位、B 近期重要动态、C 演变/关系结构、D 可判真伪主张、E 解释/比较/研究。
3. 仅当复合要求必须执行另一条完整任务时标 supporting route；同义补充不得重复标注。
4. 再标 answer mode、Intent Signals、联网权限、保真词、歧义和已解析引用。

## 关键边界

- “找到”不是导航充分条件；只有 ATR ID、完整标题或可执行定位组合才属于 A。
- “最近有什么趋势”默认属于 B；明确要求时间演变、关系或结构才属于 C。
- “是否”不是 D 的充分条件；价值判断、选型、成本收益建议属于 E。
- `forbidden` 优先于句中其他联网字样；明确要求联网为 `explicit`，其余为 `on_demand`。
- 保真词必须是 Query 中独立、连续、会改变对象/范围/主张/权限的原文片段；不得把整句或普通任务词当保真词。
- `ambiguity_expected=true` 仅用于缺少可执行对象、未解析指代或定位可能多解；不因答案未知而标歧义。
- `expected_resolved_references` 只记录由公开上下文确定解析的引用，不记录模型猜测。

## 盲测构成

- 共 50 条，A–E 每类各 10 条。
- 至少 5 组 B/C、D/E 或 A/E 最小对照；两条只改变一个决定性意图。
- 至少 10 条包含歧义或其配对负例。
- 覆盖左右位置和多次指代、显式联网/禁止联网、未知中英文实体、标题片段、复合任务、否定主张和相对时间。
- 新样本不得复用开发集和已解封挑战集的具体 Query、实体—措辞组合或 Gold 理由。

## 一次性纪律

- 独立出题 Agent 同时生成公开 query-only 文件与 sealed Gold，只返回路径和 SHA-256，不回显标签。
- 主流程在读取 sealed Gold 前冻结预测文件；预测生成器拒绝读取 `sealed/` 路径。
- 预测落盘后才允许评分进程读取 Gold。若未过 Gate，该数据集立即转为校准集，后续不得再次称为盲测。
- 实现、Schema、生成器、评分器或本口径任一哈希变化，都必须重新创建全新的封存盲测。

## 进入下一阶段的 Gate

- Schema 与语义合同：100%。
- 主路线总体准确率 ≥ 85%，每条路线 ≥ 80%。
- 最小对照两条都正确：100%。
- 显式联网与禁止联网：100%。
- 保真词 micro F1 ≥ 85%，关键权限/日期/金额/ATR ID 不得漏失。
- 歧义检测 precision、recall 均 ≥ 80%。
- 完整投影精确匹配 ≥ 70%。

通过只允许进入“影子 Query Rewrite/Prompt Package 合同设计”的下一 Gate；仍不自动授权生产接入。
